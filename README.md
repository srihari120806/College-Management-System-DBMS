# 🎓 EduCore — College Management System DBMS

EduCore is a web-based college management application that demonstrates how academic information can be organized through dedicated **Admin** and **Student** portals.

The project focuses on practical database-management workflows, role-based interfaces, academic records and administrative operations in a single responsive application.

## ✨ Core Modules

### 🔐 Authentication
- Separate Admin and Student login modes
- Demo credentials for testing
- Role-specific dashboards and navigation

### 📊 Admin Dashboard
- Total student, course, faculty and enrollment statistics
- Recent enrollment overview
- Department distribution
- Fee collection overview

### 👥 Student Management
- Student records and profiles
- Department and year information
- CGPA and academic status
- Search and department filtering

### 📚 Course Management
- Course records and course codes
- Department and credit information
- Faculty assignment
- Seat information

### 👨‍🏫 Faculty Management
- Faculty profiles
- Faculty IDs and departments
- Designation and assigned courses

### 📋 Enrollment Management
- Student-course enrollment records
- Semester tracking
- Enrollment dates and status

### 📝 Academic Records
- Course-wise grades
- Marks and grade display
- Semester-based academic tracking

### 💰 Fee Management
- Fee records and payment status
- Dashboard-level fee collection overview

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- DBMS concepts
- Responsive single-page interface

## 🎯 What This Project Demonstrates

- Role-based UI design
- CRUD-style academic management workflows
- Search and filtering
- Dashboard data visualization patterns
- Form validation and interactive UI components
- Structured management of students, courses, faculty, enrollments, grades and fees

## 🚀 How to Run

1. Clone or download the repository.
2. Open `index.html` in a modern web browser.
3. Use the demo login credentials shown on the login screen.
