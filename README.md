# 🎓 College Management System DBMS

A web-based College Database Management System designed to manage academic information through separate Admin and Student portals.

## ✨ Features
- 🔐 Admin and Student login portals
- 👥 Student management
- 📚 Course management
- 👨‍🏫 Faculty management
- 📋 Enrollment management
- 📝 Grade and CGPA tracking
- 💰 Fee management
- 📊 Dashboard with academic statistics
- 🗓️ Student timetable view
- 👤 Student profile portal

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Database management concepts

## 🚀 How to Run
1. Download or clone the repository.
2. Open the main HTML file in any modern web browser.
3. Use the demo login credentials shown on the login page.
