# 🎓 EduCore — College Management System DBMS

EduCore is a web-based college management application demonstrating academic information management through dedicated Admin and Student portals.

## ✨ Core Modules
- 🔐 Admin and Student authentication modes
- 📊 Admin dashboard with key academic statistics
- 👥 Student management and search
- 📚 Course management
- 👨‍🏫 Faculty directory
- 📋 Enrollment management
- 📝 Grades and academic performance
- 💳 Fee management and collection overview
- 📱 Responsive interface patterns

## 🎨 Modern UI
The repository now includes `modern_dashboard.html`, a polished dashboard concept with:
- Fixed navigation sidebar
- Professional dark enterprise UI
- KPI cards
- Recent enrollment activity
- Department distribution visualization
- Searchable student and course tables
- Faculty, grades and fee views
- Responsive layouts for smaller screens

Open `modern_dashboard.html` directly in a browser to preview the redesigned dashboard.

## 🛠️ Technology Stack
- HTML5
- CSS3
- JavaScript
- DBMS concepts
- Responsive single-page interface

## 🎯 What This Project Demonstrates
- Role-based UI design
- CRUD-style academic management workflows
- Search and filtering
- Dashboard visualization patterns
- Form validation and interactive components
- Structured student, course, faculty, enrollment, grade and fee management

## 🚀 How to Run
1. Clone or download the repository.
2. Open `index.html` for the complete interactive application.
3. Open `modern_dashboard.html` for the redesigned UI preview.
4. Use the demo credentials shown on the login screen.
